# 拆螺丝 · Screw Puzzle

一个纯 HTML5 + Canvas 的“拆螺丝”休闲解谜游戏，无任何依赖、无构建步骤、无素材文件（图形全部 Canvas 绘制、音效全部 WebAudio 合成）。双击 `index.html` 或起任意静态服务器即可玩，也可以直接部署到公网。

## 玩法

- 点击螺丝把它拆下：**优先进同色收集盒**——顶部两个盒子的颜色由系统实时指定，匹配哪个进哪个，都不匹配进备选格；
- **盒子颜色 = 剩余 ≥3 颗的颜色里，备选格存量最多者优先（自动流转），并列比当前可点数量**——保证盒色拿得到、末局一定刚好契合（每色总数是 3 的倍数，按此规则开盒末局不会剩下凑不齐的半盒）；
- 盒子集满 3 颗同色即完成，整个盒子打包飞出，系统按同一规则预生成下一个，并把备选格里同色螺丝自动吸入（可连锁）；与盒色相同的板载螺丝有虚线呼吸圈提示；
- **备选格里同色满 3 颗也会自动消除**（与盒内消除等效，双保险）；
- 不匹配的螺丝进**备选格**（5 格，可加到 7），备选格满了再拆即失败；某盒颜色剩余不足时会自愈换色（盒内螺丝退回备选格）；
- **点顶部「第 N 关」胶囊打开选关面板**，点任意已解锁关卡直接跳转（点空白处关闭）；
- 被上层玻璃板压住的螺丝点不动（板半透明，能看到下面一层的螺丝）；
- 一块板的螺丝拆完后整板掉落，露出更里层；
- 玻璃板有 6 种形状（圆角矩形/椭圆/方圆/四瓣花/心形/六边形）与 6 种粉彩配色，遮挡判定跟随实际形状；
- 板由剩余螺丝悬挂支承：绕剩余螺丝质心做**重力单摆**——只剩一颗螺丝时整板会大幅旋转垂坠到螺丝下方来回摆动（此时板是"挂着"而非"压着"，不再遮挡下层）；多颗时被钉住只小幅倾斜；拆螺丝时按力矩甩动；
- 道具栏：**加孔位**（备选格 +1）、**清空孔位**（清空备选格并撤销即将触发的失败），每关各一次；
- 顶部 HUD：关卡胶囊（可点选关）+ 每板进度点（掉落变浅）+ 整体进度百分比；
- 关卡由种子随机生成，**每关都经过平铺规则求解器验证必然有解**（双盒 + 备选格的分格容量严格大于平铺模型，且逐色消除规则一致，通关路径必然可执行）；生成结果按关卡号缓存（localStorage），二次进入秒开；通关进度自动存档。

```bash
python -m http.server 8914 --directory .

```

## 部署到公网

整个游戏就是一个静态文件夹，任选其一：

- **Cloudflare Pages**（国内访问通常没问题）：控制台创建项目 → 直接上传本文件夹，或推到 GitHub 后连接仓库；
- **Vercel / Netlify**：拖拽文件夹部署；
- **itch.io**：打包 zip 上传，还能得到一个游戏展示页。

纯单机不需要任何后端；以后要加排行榜再补一个 serverless 接口即可。

## 文件结构

```
index.html        入口与画布
js/rng.js         可播种随机数（同关卡号必同图）
js/audio.js       WebAudio 合成音效（无音频文件）
js/levels.js      关卡生成器 + 可解性求解器（DFS + 失败态记忆化）
js/game.js        玩法逻辑：点击/遮挡/槽位/三消/掉落/摆动物理/胜负
js/render.js      全部绘制：半透明钢板、螺丝、槽位、HUD、结算
js/main.js        画布适配（letterbox）、输入、主循环
test/test-levels.js  Node 下批量验证 1~40 关（可解性、颜色配额、耗时）
```

### 核心设计

- **逻辑坐标系固定 390×740**，渲染与输入各自做 letterbox 变换，天然适配手机竖屏与桌面窗口；
- **关卡 = 板的形状堆叠（z 序）+ 孔位（本地坐标）+ 颜色配额**。6 种板形状在 `levels.js` 的 `PlateShapes` 里各有一个解析内外判定，遮挡判定、孔位采样与渲染轮廓共用同一套数学（改动形状只需改这一处）；每种颜色螺丝数必为 3 的倍数；求解器用位掩码表示剩余螺丝集合，验证“在 5 格槽位不爆的前提下可清空”；
- **改 JS 后记得把 `index.html` 里脚本引用的 `?v=N` 版本号 +1**，避免浏览器缓存旧文件造成新旧混跑；
- **假物理**：板掉落、螺丝飞行都是补间动画；板的悬挂摆动是绕剩余螺丝质心的阻尼弹簧（拆除瞬间按偏心力矩踢一角速度），只影响表现与极小的判定容差，不影响求解器结论。

## 移植到 QQ / 微信小游戏

代码按可移植性组织，移植要点：

1. 入口换成小游戏工程模板，`canvas` 改为 `qq.createCanvas()` / `wx.createCanvas()`；
2. `localStorage` 换成 `qq.setStorageSync`（已集中在 `js/game.js` 的 `Store`）；
3. `js/audio.js` 换成 `qq.createInnerAudioContext()`（其余代码不依赖声音实现）；
4. 输入用 `qq.onTouchStart`，把触摸点换算成逻辑坐标后调用 `Game.clickLogical(x, y)`；
5. 关卡生成、玩法逻辑、绘制代码（纯 Canvas 指令）可原样复用。
